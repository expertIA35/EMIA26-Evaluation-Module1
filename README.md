## 📋 Description du projet

Ce dépôt contient mon évaluation pour le **Module 1** du Master "L'IA pour les Managers Innovants" (EMIA 26).

### 🔍 **Bloc 1 : MesLivres.com - Segmentation client**
- **Contexte** : Entreprise e-commerce de vente de livres avec 4 000 clients
- **Données** : Historique 12 mois (fréquence, panier, catégories, temps, taux retour, canal)
- **Solution** : Clustering avec K-Means (Machine Learning non supervisé)

### 📝 **Bloc 2 : SavoirPlus - Résumé automatique de réunions**
- **Contexte** : Capitaliser sur les échanges d'experts-formateurs
- **Solution** : Prompt Engineering + RAG avec Human-in-the-loop

## 🛠️ Technologies utilisées
- Python 3.10+, Scikit-learn, Pandas
- Azure OpenAI, Marp, Figma
- Git/GitHub

## 📊 Résultats clés
- **Bloc 1** : 4 segments identifiés (Fidèles 25%, Occasionnels 40%, À risque 15%, Nouveaux 20%)
- **Bloc 2** : Économie de 250h d'annotation, processus fiable Human-in-the-loop
